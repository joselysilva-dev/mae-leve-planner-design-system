# Mãe Leve Planner — Design System

Design System criado para o aplicativo mobile **Mãe Leve Planner**, desenvolvido como desafio da Formação UX Designer da DIO.

## Objetivo

Criar uma linguagem visual consistente, acolhedora, acessível e reutilizável para apoiar o desenvolvimento do aplicativo Mãe Leve Planner.

O aplicativo busca ajudar mães a organizar tarefas, compromissos, rotina familiar e momentos de autocuidado.

## Princípios do projeto

- Clareza
- Acolhimento
- Simplicidade
- Acessibilidade

## Conteúdo do Design System

O projeto apresenta:

- Paleta de cores e tokens;
- Tipografia;
- Escala de espaçamentos;
- Ícones;
- Botões e seus estados;
- Campos de entrada;
- Mensagens e notificações;
- Átomos, moléculas, organismos e templates;
- Exemplos de telas mobile;
- Orientações de acessibilidade baseadas na WCAG AA;
- Documentação das decisões visuais.
